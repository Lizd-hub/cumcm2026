## 离线配对实验

使用种子 20260910—20260929，两种问题各 20 个场景，每场景运行基线和主动定位，共 **80 次**。最终全部完整清除，程序清除数与模拟器事后真值逐次一致。

| 问题 | 基线平均虚拟总耗时 / 秒 | 主动定位平均虚拟总耗时 / 秒 | 平均总耗时降低 |
| --- | ---: | ---: | ---: |
| 问题三：全向 | 24071.93 | 12019.45 | 50.07% |
| 问题四：混合 | 34000.72 | 24719.42 | 27.30% |

“降低”按 1−两组总耗时之比计算，不是单个场景降低比例的平均值。基线为覆盖发现后直接光学兜底；主动策略使用局部选点及包围圆清除。

本次分为四个并行批次执行，每批五个种子，结果保存在 outputs/benchmark/batch0—batch3。并发只发生于独立离线实验，单次运行内的动作仍串行。现实耗时受并发负载影响，不能作为官方接口吞吐或正式成绩。

最终配置中现实收尾预留为 30 秒；评分剔除了已有 direction 观测不允许的 5 米内场景。此调整未改变这批样本的最终轨迹，但纠正了交会质量显示。离线固定哈希误差与随机位置是自建实验假设，不是官方误差场或目标分布。

复现旧版完整实验可运行 `python -m legacy_solution.experiments.benchmark`；默认串行执行同样 20 个种子，虚拟结果确定，现实耗时会随硬件变化。逐次结果见 outputs/benchmark/summary.json，配对差值见 outputs/tables/paired_comparison.csv。

## 使用边界

1. 实现提供有限覆盖和光学兜底，不宣称虚拟时间全局最优。
2. 在线候选精算有约 0.2 秒预算，可能退回快速代理；网络时延和计算机速度会影响在线路径。
3. 官方演练、正式测试、加密日志导出与人工录入成绩尚未执行；需在实际模拟器中另行核验。
4. 生成目录 outputs 默认被 Git 忽略；提交支撑材料时应包含所需结果、配置、图表和原名官方日志。
