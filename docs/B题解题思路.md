## 3. 题设、符号与优化目标

### 3.1 不得改变的条件

- 目标位置在圆域内，半径 1800 米；机器狗可以到圆域外检测或清除。
- 频道为 1—20，每频道至多一个目标，目标频道不变；问题三、四目标总数为 10—16，但接口不返回其具体值。
- 有效接收半径为 1000—1500 米；**1000 米不是目标离检测点的最小距离**。
- 全向源在所有方位发射；定向源在某未知朝向两侧各 90°，含边界，向外无信号。
- 示向度从正东逆时针计角；真实误差有界于 ±1°，题目没有给出独立、均匀或高斯分布。
- 同一地点重复检测不会改变当地固定误差，不能以重复测量平均值声称提高精度。
- 移动速度 5 米/秒；移动时不能检测；当前频道初始为 1。
- 光学清除距离不超过 20 米，独立于目标发射朝向；`near` 表示处于发射覆盖内且距离不超过 5 米。

### 3.2 主要符号

| 符号 | 定义 |
| --- | --- |
| \(\Omega=\{g\in\mathbb R^2:\|g\|\le1800\}\) | 目标圆域 |
| \(g_j,R_j,n_j\) | 频道 \(j\) 的目标位置、接收半径、定向单位向量 |
| \(p,s_i,q\) | 当前位置、历史检测点、候选检测点 |
| \(\theta_i,\delta\) | 示向度与采用的误差半角 |
| \(u(\theta)=(\cos\theta,\sin\theta)\) | 方向单位向量，计算前转弧度 |
| \(W(s,\theta,\delta)\) | 以 \(s\) 为顶点的正向角域 |
| \(P_j,K_j\) | 仅测向半平面形成的多边形、结合其他信息的可行集 |
| \(D(K),c(K),\rho(K)\) | 直径、最小包围圆圆心及半径 |
| \(N_m,N_{sw},N_s,N_f,L\) | 检测数、检测频道切换数、清除成功数、清除失败数、路程 |

理论推导使用 \(\delta=1^\circ\)。接口示向度保留两位小数，为兼容末位量化，实现默认用 \(\delta=1.01^\circ\)；若明确验证采用四舍五入，可改为 \(1.005^\circ\)。此余量不是修改题设误差分布。额外使用绝对几何容差 \(10^{-6}\) 米、清除安全阈值 19.9 米。

### 3.3 耗时模型与目标

虚拟总耗时严格按附件计算：

\[
T=\frac{L}{5}+5N_m+N_{sw}+5N_s+3N_f.
\]

每次 `/measure` 产生移动、必要的频道切换与 5 秒检测耗时；每次 `/clear` 产生移动和 3 或 5 秒耗时，但不改变测向机当前频道。`/enter`、`/exit` 不增加虚拟时间，不要求回原点退出。

目标使用优先级而非任意加权：先确保清除全部实际目标，再在完整清除的策略中尽量减少 \(T\)。演练阶段报告：

\[
\eta=\frac{N_s}{N_{\mathrm{true}}},\qquad
\bar T=\frac{T}{N_s}.
\]

当 \(N_s=0\) 时，平均时间记为“不适用”，不能填 0。低覆盖率下的低平均时间不代表策略优秀。程序现实运行时间与 \(T\) 分开记录；每次 5 秒检测是虚拟成本，不应调用 `sleep(5)`。

## 4. 问题一：交会定位区域直径与包围圆

### 4.1 将角域写成半平面

二维叉积记为 \([a,b]=a_xb_y-a_yb_x\)。令

\[
a_i=u(\theta_i-\delta),\quad b_i=u(\theta_i+\delta),
\]

则

\[
W_i=\{x:[a_i,x-s_i]\ge0,\ [b_i,x-s_i]\le0\},\qquad
P=\bigcap_iW_i.
\]

两条约束共同限定正向窄角域，不能把它替换为包含反向射线的无限长条带。向量形式天然处理 359.8° 与 0.2° 的跨零问题，避免直接比较角度大小。

### 4.2 直径算法

优先实现便于核验的基线，之后按需要优化。

1. 将 \(2m\) 个半平面统一为 \(Ax\le b\)，线性可行性检查区分空集。
2. 分别最小化、最大化 \(x,y\) 坐标；任一目标无界，说明非空定位集无界，其直径为无穷。
3. 枚举边界直线对，非平行时求交点，保留满足全部约束的点，按容差去重。
4. 对保留点求凸包。退化成单点时直径为 0；退化成线段时取两端距离。
5. 对凸包顶点枚举点对，求最大距离及相应端点。

有界凸多边形的最远距离可在顶点对上取得：固定一点时，距离是凸函数，其最大值可取于顶点；对另一点重复该论证即可。

```python
def polygon_diameter(observations):
    H = bearing_halfplanes(observations)
    if not feasible(H):
        return {"status": "empty"}
    if any_coordinate_extremum_unbounded(H):
        return {"status": "unbounded", "diameter": float("inf")}
    vertices = []
    for line_a, line_b in unordered_pairs(boundaries(H)):
        if nonparallel(line_a, line_b):
            x = intersection(line_a, line_b)
            if satisfies_all(x, H):
                vertices.append(x)
    hull = convex_hull(deduplicate(vertices))
    return farthest_pair_with_degenerate_handling(hull)
```

边界对枚举及逐约束检查为 \(O(m^3)\)；若凸包有 \(k\) 个顶点，点对枚举为 \(O(k^2)\)。测向次数较小时足够。优化版使用 \(O(m\log m)\) 半平面交及 \(O(k)\) 旋转卡壳，但保留基线作交叉校验。

**数值边界：**近乎平行会产生远交点，不能把它当成精确定位；空集先检查角度方向、频道关联、舍入和容差；不允许静默删掉不利观测。理论无界情形不能用任意大矩形截断后报告“有限直径”。

### 4.3 同直径圆不一定覆盖区域

取边长为 \(d\) 的等边三角形，其区域直径为 \(d\)，最小包围圆半径为 \(d/\sqrt3\)，大于 \(d/2\)。因此不存在直径恰好为区域直径的圆覆盖任意此类区域；取最远点对的中点作圆心也不能解决该问题。

应计算

\[
\rho(K)=\min_c\max_{x\in K}\|x-c\|.
\]

对多边形只需包住全部顶点；最小包围圆由两个或三个边界顶点支撑。采用固定随机种子的增量最小包围圆算法，验证时用两点直径圆及三点外接圆枚举进行对照。

- \(\rho(K)\le20\) 是到其圆心保证一次清除成功的充分条件；实现使用 \(\rho\le19.9\)。
- \(D(K)\le40\) 仅为存在半径 20 米包围圆的必要条件，不充分。
- 若不计算包围圆，\(D(K)\le20\) 时到任意 \(K\) 内点清除是保守充分条件。

### 4.4 多边形与实际可行集的区别

后续问题还可以结合

\[
K_j=\Omega\cap\bigcap_{i\in I_j^+}W_i
        \cap\bigcap_{i\in I_j^+}B(s_i,1500),
\]

其中 \(I_j^+\) 为返回 `direction` 的记录。圆盘约束会形成曲边边界；加入无信号或清除失败约束还可能使集合非凸。

实现维护一个**包含真实可行集的凸多边形外包络**用于安全判定：用 128 个均匀法向的切线半平面外逼近每个圆盘，再与测向半平面相交。它是外接多边形，不能误用内接多边形剔除真值。用其顶点包围圆会偏保守，但保留保证。内圈排除等非凸信息另存，用于评分与减少兜底尝试，不能用离散样本的包围圆冒充完整集合保证。

## 5. 问题二：第二检测点策略与候选区域

### 5.1 首次观测能确定什么

首次在 \(s_1\) 得到示向度 \(\theta_1\)，则

\[
K_1=\Omega\cap W(s_1,\theta_1,\delta)\cap B(s_1,1500).
\]

返回 `direction` 还意味着距离大于 5 米，但为保持凸性可以暂不利用这一排除。信号强弱数值并不在接口返回中，不得据此虚构距离估计。

两次交会的定位误差通常在夹角趋近 0° 或 180° 时放大，近直角时较稳定；但只追求直角可能导致远距离绕行或超出接收范围。故同时考虑目标距离不确定性与移动成本。

### 5.2 保证再次接收的候选区域

一个简单充分集合为

\[
\mathcal C_{1000}=\bigcap_{g\in K_1}B(g,1000)
=\{q:\max_{g\in K_1}\|q-g\|\le1000\}.
\]

全向源对集合内任一点均可接收，但距离过近时可能返回 `near`，并非一定返回示向度。使用外包络顶点计算最大距离，所得候选集合仍保守有效。该集合可能为空。

利用首次已经收到信号，还可给出更宽的充分集合：

\[
\mathcal C_{\mathrm{safe}}=
\{q:\forall g\in K_1,\ \|q-g\|\le\max(1000,\|s_1-g\|)\}.
\]

原因是未知 \(R\) 同时满足 \(R\ge1000\) 及 \(R\ge\|s_1-g\|\)。核心实现先使用较容易验证的 \(\mathcal C_{1000}\)；后者仅在能够完成连续集合验证时作为增强，有限目标采样不能证明该条件成立。

### 5.3 可实施的离散候选生成

令 \(e=u(\theta_1)\)，\(e_\perp=(-e_y,e_x)\)，生成

\[
q=s_1+a e+b e_\perp,
\]

其中默认

\[
a\in\{0,100,250,500,750\},\qquad
b\in\{\pm50,\pm100,\pm200,\pm400\}\ \text{米}.
\]

另加入外包络中心、下一覆盖检测点。保留 \(\|q\|\le3300\) 且与已有检测点至少相距 10 米的候选；3300 米是限制无效绕行的策略边界，不是模拟器硬约束。后续观测以当前位置为移动成本起点，在外包络中心方向重建候选坐标。

候选分两组：满足安全充分条件的候选；未满足该条件、但可能获得更好交会效果的候选。优先从安全组选择；组为空时才进入带失联风险的候选组，不宣称其保证接收。

### 5.4 评分与最终选择

从可行外包络获取顶点、边中点与最多 128 个确定性内部采样点，过滤已知排除区，构成场景集 \(G\)。场景是数值设计工具，不代表题目给定目标位置分布。

对候选 \(q\)、场景 \(g\)，定义交会质量

\[
\gamma(q,g)=
\frac{|[g-s_1,g-q]|}{\|g-s_1\|\,\|g-q\|}.
\]

近距离分母退化时转为光学清除候选。筛选后，对每个场景和误差 \(\varepsilon\in\{-\delta,0,\delta\}\) 构造第二测向角域，计算更新后外包络半径。建议采用秒量纲的代理评分：

\[
J(q)=\frac{\|q-p\|}{5}+5+
\mathbf1(j\ne c_{\mathrm{radio}})
+\frac{2\widehat\rho_{\mathrm{worst}}(q)}5
+60[1-\widehat p_{\mathrm{recv}}(q)].
\]

其中 \(\widehat\rho_{\mathrm{worst}}\) 为场景集合上的最大后验半径；\(\widehat p_{\mathrm{recv}}\) 以 \(R=1000\) 的场景覆盖比例计算。最后两项是可调启发式，并非真实剩余时间或统计概率。误差三点采样亦不是连续误差的严格极大值求解。

```python
def choose_next_measurement(state, target):
    candidates = generate_candidates(state, target)
    safe = [q for q in candidates if max_vertex_distance(target.outer, q) <= 1000]
    pool = safe if safe else candidates
    scored = [(scenario_score(q, state, target), q) for q in pool]
    # 平分时依次选移动短、最小场景交会质量高、坐标字典序小的点
    return deterministic_argmin(scored)
```

### 5.5 第二点无信号与退化处理

全向源返回 `no_signal` 时，可以严格排除 \(B(q,1000)\) 内的目标位置，即保留 \(\|g-q\|>1000\)。更强地，结合历史正检测可排除满足

\[
\|q-g\|\le\max(1000,\max_{i\in I_j^+}\|s_i-g\|)
\]

的候选位置。实现先使用简单排除，保留凸外包络以保证安全。

接收到方向但定位集收缩不足时，改选侧向点，不在原地重复测向；`near` 则直接原地 `/clear`。连续两次新位置无信号，或局部主动检测累计达到 8 次后，转入第 6.4 节的有限光学兜底。

## 6. 问题三：全向源的完整搜索与清除

### 6.1 确定性覆盖点与证明

采用覆盖点集

\[
S_{\mathrm{omni}}=
\{-1800,-600,600,1800\}^2,
\]

共 16 点，允许圆域外的点。整个目标圆域包含在对应的正方形内，对任意目标 \(g\) 都存在网格顶点 \(s\)，每个坐标差不超过 600 米，故

\[
\|g-s\|\le\sqrt{600^2+600^2}
=848.53<1000\le R_g.
\]

因此对任意未清除的全向源，在这些点检测其频道至少会得到一次 `direction` 或 `near`。这是保底构造，不宣称检测点数最少。

默认从离当前位置最近的网格角点开始蛇形遍历；四种角点入口中选择总入场路程最小者，平分按坐标字典序。可在原点先扫描全部 20 频道以尽早发现目标；它是额外信息，不替代网格覆盖证明。

### 6.2 逐频道状态与覆盖证书

每频道保存状态：`unknown`、`detected`、`cleared`、`absent_certified`。保存全部正检测、无信号、失败清除位置、凸外包络及覆盖节点完成标志。

- `direction`：标为 `detected`，更新外包络。
- `near`：立即原地清除，成功后标为 `cleared`。
- `no_signal`：记录该节点已检测；对全向源加入安全排除信息。
- `success`：永久标为 `cleared`，以后不再检测该频道。
- 尚无正检测的频道，在全部 16 个覆盖节点均得到无信号后，标为 `absent_certified`。

已发现却未清除的频道即便之后测不到信号，也不能标记为不存在。只有当全部 20 个频道均为 `cleared` 或 `absent_certified`，才建立默认的完整清除证书。成功清除达到题设上界 16 个也足以证明完成，可作为严格的提前退出条件；达到下界 10 个不够。

### 6.3 扫描与定位的调度

基线流程：在覆盖节点扫描所有 `unknown` 频道，当前检测频道若在列表中则先测，之后按频道升序；将新发现目标加入待办队列。`near` 原地立即清除。扫描结束后处理待办目标，再回到尚未完成的覆盖路线。

待办目标按估计完成成本排序：

\[
C_j=\frac{\|p-c_j\|}{5}+5+
6\left\lceil\log_2\max(1,\rho_j/19.9)\right\rceil.
\]

此处倍增收缩仅是排序代理，不是已证明的收敛率。平分时先同频道目标，再频道编号小者。选定目标后最多执行 8 次新位置主动测向，随后必须完成清除或进入有限兜底，避免任务饥饿。

增强策略允许把下一覆盖节点纳入主动测向候选，复用已有路线；必须保留逐频道覆盖节点完成记录，不能以“经过附近”冒充停点检测。

### 6.4 单次有效测向后的有限光学兜底

这是将“发现”转化为“最终清除”的独立保证，适用于问题三和问题四。取任一历史有效测向 \((s,\theta)\)，以其方向为纵轴：

\[
g=s+t e+z e_\perp.
\]

由距离不超过 1500 米及误差不超过实现半角 \(1.01^\circ\)，有

\[
0\le t\le1500,\qquad |z|\le1500\sin1.01^\circ<26.45.
\]

因此目标位于矩形 \([0,1500]\times[-40,40]\) 内。使用光学候选点

\[
Q=\{s+20k e+20\ell e_\perp:
k=0,\ldots,75;\ \ell=-2,\ldots,2\}.
\]

共 380 点。任意目标在纵、横方向距最近网格点均不超过 10 米，故最近点距离不超过 \(10\sqrt2\approx14.15<20\) 米。逐点对该频道 `/clear`，必有一次成功，且不依赖无线电朝向或测向误差的统计性质。

按纵轴逐列、横轴交替方向蛇形访问；完整矩形内部路线长度为 \(76\times80+75\times20=7580\) 米。若完整遍历，局部移动与清除上界为 \(7580/5+379\times3+5=2658\) 秒，另加到首点的移动时间。这是保守上界，不是预期成绩。

可先检测靠近可行集中心的清除点，但默认优先保留蛇形顺序；只在能证明某网格点的 20 米圆盘与完整可行集无交集时删除该点。场景采样为空不能作为删除依据。一次有效测向即已保证此兜底成立，无需假定后续还会有信号。

### 6.5 最小包围圆清除与失败更新

若当前外包络最小包围圆半径不超过 19.9 米，则移动至圆心清除。若返回失败，说明数据关联、数值外包络或状态实现存在问题，应记录异常并回到保留原始观测的兜底流程，不能把目标改为不存在。

一般的试探清除失败，只说明该频道未清除目标不在当前点的 20 米圆盘中；对已经确认存在的目标加入此排除约束。`near` 后原地清除也应成功，失败按一致性异常处理。

## 7. 问题四：混合定向源的扩展

### 7.1 定向观测模型

对定向源，接收条件为

\[
\|s-g\|\le R,\qquad n\cdot(s-g)\ge0,
\]

其中 \(n\) 指向源向外发射的中心方向。注意这里是“目标指向检测点”向量；测向示向度则是“检测点指向目标”，两者不能混淆。

无信号意味着距离超界或位于发射背面。不能照搬问题三的规则排除整个 \(B(s,1000)\)。默认实现只用正测向收缩位置外包络，把无信号用于记录覆盖证书，避免错误排除真值。

可选增强维护 \((g,R,n,\mathrm{type})\) 联合可行状态，以历史正负观测过滤；该增强仅在基线稳定后实施，不是完成本方案的前置条件。离散朝向拟合只能用于选点评分，不能单独证明不存在目标。

### 7.2 对任意朝向有效的覆盖点

采用

\[
S_{\mathrm{mixed}}=
\{-2100,-1500,-900,-300,300,900,1500,2100\}^2,
\]

共 64 点，网格边长 600 米，整个圆域严格包含在网格外框内。保留圆域外节点，不能直接裁掉，否则边缘朝外发射的源可能漏检。

任意目标 \(g\) 属于某个闭网格单元，记四顶点 \(v_1,\ldots,v_4\)。有

\[
\|v_i-g\|\le600\sqrt2=848.53<1000\le R.
\]

又因 \(g\) 是四顶点的凸组合，存在 \(\lambda_i\ge0\)、\(\sum_i\lambda_i=1\)，使

\[
\sum_i\lambda_i(v_i-g)=0.
\]

若四顶点均处于发射背面，即 \(n\cdot(v_i-g)<0\)，取加权和便与 0 矛盾。因此至少一个顶点满足 \(n\cdot(v_i-g)\ge0\)。结合距离条件，该点必能检测到目标。目标恰在网格边或顶点时，闭半平面的边界包含规则仍保证结论成立。

故在 64 点对未知频道逐一检测，对全向源与任意未知定向源都可得到完整发现保证。该方案没有使用“定向源约一半概率能被接收”之类未经给定的统计假设。

### 7.3 定向条件下的主动定位

问题二的 \(\mathcal C_{1000}\) 在本问只能保证距离，不能保证在发射前面。候选评分可以使用历史正信号点作为朝向线索，但必须允许新点无信号。

默认采用与问题三相同的候选生成，正观测更新位置，连续两次无信号或达到 8 次局部主动测向后进入光学兜底。若最小包围圆已满足 19.9 米阈值，直接清除，不必为了“再次检测有信号”绕到发射正面。

### 7.4 完整性与资源约束的边界

理论上，有限覆盖点保证发现所有目标；每个被发现目标的有限光学网格保证清除；逐频道终止证书保证不会遗漏未知频道。这是有限完成性证明。

该证明本身不等于“任意机器、网络和案例都可在 20 分钟现实时间内完成”。现实请求时延没有确定上界，必须实测吞吐；虚拟时间也要监测 100 小时上限。程序在剩余预算不足时不能伪称获得完整清除证书。

资源评估基准：混合覆盖全扫描至多 1280 次检测，原点额外扫描至多 20 次，16 个目标主动检测至多 128 次，光学兜底至多 6080 次清除。这个粗上界约 7510 次业务动作，加进入与退出；实际因已清除频道跳过、提前成功通常更少，但需要演练证实。按该上界估计，若可用 1140 秒，则全流程平均每动作连同计算需约 0.15 秒以内，说明减少兜底与限制候选求值时间的重要性。

### 8.1 模块职责

| 模块 | 输入 | 输出与不变量 |

| 几何模块 | 历史正测向、目标圆域、接收上界 | 保守外包络、直径、包围圆；不得排除真实目标 |

### 8.2 主流程

```python
def solve(problem_kind, client):
    entered = client.enter_with_idempotency()
    state = initialize(position=(0, 0), radio_channel=1,
                       real_budget=entered["remaining_real_duration_s"])
    checkpoints = snake_grid(problem_kind)
    scan_unknown_channels_at((0, 0), state, client)
    resolve_pending_targets(state, client, max_extra_measures=8)

    for point in checkpoints:
        check_time_and_action_budget(state)
        scan_unknown_channels_at(point, state, client)
        # 即使扫描中因 near 触发 clear，也仍回到该节点处理未扫描频道
        update_absence_certificates(state, problem_kind)
        resolve_pending_targets(state, client, max_extra_measures=8)
        if complete_certificate(state) or state.cleared_count == 16:
            break

    assert_no_unresolved_target_before_claiming_complete(state)
    client.exit_with_idempotency()
    save_local_summary(state)

def resolve_one_target(target, state, client):
    extra, consecutive_no_signal = 0, 0
    while not target.cleared:
        if target.has_near_observation_at_current_position:
            attempt_clear_here(target)
        elif minimum_enclosing_radius(target.outer) <= 19.9:
            attempt_clear_at_enclosing_center(target)
        elif extra >= 8 or consecutive_no_signal >= 2:
            clear_by_finite_bearing_grid(target)  # 成功后立即停止
        else:
            q = choose_next_measurement(state, target)
            result = measure_and_update(q, target)
            extra += 1
            consecutive_no_signal = (
                consecutive_no_signal + 1 if result == "no_signal" else 0
            )
```

上述是策略伪代码，异常处理由客户端负责。若现实预算不足、接口关闭或一致性异常无法恢复，应保存未完成状态，不能用断言错误代替实际的异常收尾。安全时间允许时主动退出，报告未取得完整证书；正式测试的完整性成绩以实际结果为准。

## 9. 模拟器接口与工程注意事项

### 9.1 接口及状态

默认地址 `http://127.0.0.1:2026`，四个精确路径均为 POST：

| 路径 | 请求字段 | 成功后的专用响应 |
| --- | --- | --- |
| `/enter` | `arena_id`、`robot_id`、`request_id` | `remaining_real_duration_s` 等限时信息 |
| `/measure` | 公共字段、`position: {x, y}`、`channel` | `measure_result`；仅 `direction` 有 `svd_deg` |
| `/clear` | 公共字段、`position: {x, y}`、`channel` | `clear_result` |
| `/exit` | 公共字段 | `exit_reason`，成功主动退出为 `user_exit` |

`arena_id` 固定为 `default`，`robot_id` 为当前登录参赛队号，通过运行时配置传入，不写入公开论文与共享示例。频道为 1—20 整数；坐标必须有限且各分量绝对值不超过 2000000。请求为无 BOM UTF-8 JSON，`Content-Type: application/json`，不增加协议外字段。

检测结果使用 `no_signal`、`near`、`direction`；清除结果使用 `success`、`no_target_in_range`。不要依赖界面中文字符串。

### 9.2 幂等、错误与日志

- 每个新动作使用会话内唯一 `request_id`，动作串行发送。
- 网络超时或连接中断后，若重试，只能重发相同路径、内容和 ID；不能换 ID 盲目再做一次。
- 同时检查 HTTP 状态和 `accepted`。`accepted=false` 不更新位置、频道与当前虚拟时间；返回的 0 不能解释为虚拟时钟归零。
- HTTP 400 或未知字段先修正请求；409 视为幂等或并发逻辑问题，不自动换 ID 掩盖；429 有界退避并检查剩余时间；500 或连接异常只按原动作有界重试。
- 默认请求超时 3 秒，同一动作最多 3 次尝试，重试退避 0.2、0.5 秒；剩余时间不足时缩短或停止重试。未明确获得动作结果时保留“不确定”，不根据猜测继续规划。
- 每次动作保存请求、响应、当地单调时钟、动作前后位置和测向机频道。用模拟器 `virtual_time_s` 与本地计时模型比对，原始日志不可覆盖。
- 结束后接口关闭，不能再调用 `/exit` 查询结束原因。异常原因以模拟器界面为准。

### 9.3 时间控制与默认参数

| 参数 | 默认值 | 性质与调参顺序 |
| --- | --- | --- |
| 几何误差半角 | 1.01° | 先保守保证，核实量化后再缩紧 |
| 光学安全半径 | 19.9 米 | 保留数值余量，不随效果任意调大 |
| 圆盘外逼近 | 128 个切线半平面 | 核验外包关系后可比较 64/128/256 |
| 全向/混合网格边长 | 1200/600 米 | 与覆盖证明绑定，不盲目放大 |
| 局部新增测向上限 | 8 次 | 比较 4/6/8，控制失联成本 |
| 连续无信号阈值 | 2 次 | 比较 1/2/3；达到后启用兜底 |
| 场景数上限 | 128 | 若求值慢，先降为 64，不能放松安全判定 |
| 单次候选选择预算 | 0.2 秒 | 超时选已算出的最好候选，无候选则兜底 |
| 光学兜底网格间距 | 20 米 | 保证最近距离小于 20 米 |

## 10. 演练与验证设计

### 10.1 几何和状态一致性检查

| 场景 | 验收要求 |
| --- | --- |
| 示向度跨 0° | 向量角域正确，真实点不被错误排除 |
| 两条测向几乎平行 | 报告较大不确定性或无界，不虚报高精度 |
| 空集、单点、线段 | 返回不同状态，直径定义正确 |
| 等边三角形 | 直径为边长，包围圆半径为边长除以 \(\sqrt3\) |
| 圆盘外逼近 | 真实圆盘被包含，不能用内接多边形替代 |
| 源位于圆域边缘、网格边或顶点 | 全向与任意定向覆盖证明适用 |
| 定向源朝圆域外发射 | 圆域外检测节点保留，不能漏检 |
| `near` 后清除 | 原地成功且耗时、频道状态正确 |
| `/clear` 失败或成功后再检测 | 测向机频道保持不变 |
| 同 ID 重试 | 不重复移动或累计虚拟耗时 |
| 清除 10 个但仍有未知频道 | 不允许以数量下界退出 |
| 20 个频道全部终态 | 可生成完整性证书 |
| 光学兜底最不利位置 | 目标距某一候选点不超过 \(10\sqrt2\) 米 |

离线几何检查应随机生成真实源和合法有界误差，并加入端点、共线等专门场景。它们用于核验程序，不代替连续覆盖证明。可用自建模拟器复现固定位置误差，但必须标明误差场构造与官方模拟器不同。

### 10.2 基线、消融与演练规模

建议开发阶段每种方案至少 10 次演练，最终固定方案在问题三、四各至少 30 次演练；这是建议样本量，不是官方次数要求，时间不足时优先保证稳定性与正式测试准备。

| 方案 | 用途 |
| --- | --- |

### 10.3 统计指标

每局记录题目类型、案例编码、算法配置、退出原因、演练结束后真值总数、成功清除数、清除比例、平均定位清除时间、总路程、检测数、频道切换数、失败清除数、兜底次数、虚拟总耗时和现实运行时间。

多局同时报告：完整清除率、各局清除比例的均值、合并清除比例 \(\sum N_s/\sum N_{\mathrm{true}}\)、完整清除案例的平均时间中位数及四分位范围。单局平均时间与合并平均时间 \(\sum T/\sum N_s\) 不混用。失败、超时均保留，不只报告成功案例。
